# Персональная веб-страница «О себе» (с поддержкой JavaScript)

Учебный проект (Лабораторная работа №4, Вариант 1: «Студент-разработчик») — интерактивная веб-страница с информацией о навыках, проектах, галереей, формой обратной связи и скриптом на JavaScript для обработки успеваемости студента.

## Особенности проекта
- **Ввод/вывод данных на JS**: интерактивное приветствие пользователя через `prompt` и `alert`.
- **Логика и функции**: инкапсулированная обработка массива баллов за лабораторные работы (поиск максимума `findMax`, фильтрация отличных оценок `filterHighScores`, расчет суммы `calculateSum`).
- **Аналитика в консоли**: вывод среднего балла, количества неудовлетворительных работ (< 50) и автоматическая выдача мотивационного сообщения в `console.log`.
- **Сетка навыков (Grid)**: оформление списка навыков карточками с плавным увеличением (`transform: scale(1.05)`), мягкой тенью и декоративным бейджем «Top skill».
- **Карточки проектов (Flexbox)**: адаптивный ряд карточек с внутренней компоновкой (иконка слева, описание и кнопка справа) и полупрозрачным оверлеем для контрастности.
- **Галерея скриншотов**: адаптивная Grid-сетка скриншотов с подписями в тегах `<figure>` и `<figcaption>`.
- **Адаптивность**: корректное отображение на мобильных устройствах, планшетах и десктопах (1, 2 и 3 колонки) благодаря `<meta name="viewport">` и медиа-запросам.
- **Интерактивность CSS**: наглядные состояния `:hover`, `:active` и `:focus` для кнопок, полей ввода и ссылок.
